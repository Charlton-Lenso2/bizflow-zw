# BizFlow ZW

BizFlow ZW is a mobile-first business management application being developed for small businesses in Zimbabwe, beginning with a real wholesale business pilot.

## Project Goals

- Manage customers, products, sales, and business transactions.
- Track customer credit, due dates, and partial repayments.
- Keep USD and ZiG records separate.
- Generate clearly marked non-fiscal receipts.
- Provide a conversational AI assistant grounded in the business's recorded data.
- Validate the application through task-based testing with the pilot business.

## Approved Scope

### Core Capstone Features

- Authentication and business onboarding
- Customer and product management
- Sales and transaction records
- Credit ledger and partial payments
- Dashboard and non-fiscal receipts
- Conversational AI assistant
- Testing with the pilot business

### Stretch Goal

- Offline support and data synchronisation

### Future Work

- ZIMRA FDMS fiscalisation

Receipts generated by the capstone are non-fiscal and must be labelled accordingly.

## Planned Technology

- Frontend: React, TypeScript, Vite, Tailwind CSS
- Backend: Node.js, Express, TypeScript
- Database and authentication: Supabase
- AI integration: Gemini API
- Validation: Zod
- Testing: Vitest and API integration tests

## Development

The project is organised as a monorepo with separate frontend and backend applications.

Implementation will follow documented architecture, database design, and API contracts.
